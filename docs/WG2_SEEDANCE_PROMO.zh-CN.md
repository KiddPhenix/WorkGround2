# WorkGround2 × Seedance 2.5 宣传片生成包

## 一句话策略

**别换掉 Claude，给 Claude 换个工作台。**

这条片面向已经习惯 Claude / Claude Code 的开发者。重点不讲“WG2 比 Claude 更聪明”，而是强调迁移成本低：Claude CLI、`CLAUDE.md`、Claude Code 的 `.mcp.json` 习惯都可以继续使用，再增加多模型协作、权限控制和 Bot 远程入口。

## 成片规格

- 时长：30 秒
- 画幅：16:9，建议 1920×1080，24 fps
- 节奏：前 5 秒痛点，10 秒完成价值转折，后 15 秒给证据和行动号召
- 生成方法：每个镜头单独生成 5–8 秒，每镜生成 3 个版本，最后剪辑拼接
- UI 镜头：优先使用图生视频；字幕、Logo 和产品名统一在剪映 / Premiere 中后期叠加

将这段放在每个 Seedance 镜头提示词末尾：

```text
高端软件产品广告，深海军蓝与黑色背景，紫色和青色光效，真实开发者工作环境，克制的科技感，细腻体积光，电影级对比度，稳定流畅运镜，16:9，24fps，画面中央和下方保留字幕安全区。画面干净、可信、专业，不生成可读文字、品牌 Logo、乱码代码或水印。
```

## 通用负面提示词

```text
禁止生成文字、字幕、Logo、水印、乱码代码；禁止改变上传截图中的任何文字、按钮、布局、颜色和窗口比例；禁止 UI 漂移、按钮融化、鼠标乱动、自动滚动、闪烁、画面抖动、过度赛博朋克、霓虹爆炸、夸张粒子、低清晰度、噪点、人物手指畸形。
```

## 生成时的关键规则

1. UI 图生视频要“锁图”：只允许 1.5%–2% 推近和局部光效。
2. Seedance 不负责生成产品字幕和 Logo，后期叠加才能保证文字完全正确。
3. 每镜生成 3 版，只选没有 UI 形变和文字漂移的版本。
4. 镜头之间用 4–6 帧紫色光扫或直接硬切，避免花哨转场。
5. 竖版 9:16 时不要裁掉 UI：把原截图完整置于画面中部，上下延展深蓝背景，字幕放底部安全区。
